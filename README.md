# SQL Query - Customer Balance Data

**CIS 310 | SQL**

## Project Overview
This exercise explores SQL queries for retrieving and analyzing customer, sales representative, and invoice information. The queries examine customer balances, credit limits, and available credit while combining information from related database tables.

## Features
- Retrieves customer balances and calculates available credit.
- Uses subqueries to compare customer balances with average or minimum balances.
- Combines customer, sales representative, and invoice data using joins.
- Applies filtering, grouping, and sorting to query results.
- Demonstrates UNION queries to combine customer result sets.
